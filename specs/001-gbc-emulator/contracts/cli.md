# 契約: コマンドラインインターフェース

LispGB が利用者に公開するインターフェースは、このコマンドラインとキー操作だけです。
挙動は RuxBoy に合わせています（spec FR-014〜FR-016、FR-019、FR-020）。

## 書式

```
lispgb [options] <ROMファイル>
```

## オプション

| オプション | 値 | 既定 | 挙動 |
|---|---|---|---|
| `-h`, `--help` | — | — | 使い方を標準出力に表示し、終了コード 0 で終わる |
| `-v`, `--version` | — | — | `LispGB <version>` を表示し、終了コード 0 で終わる |
| `--scale N` | 整数 | 設定ファイルの値（なければ 4） | 1 未満はエラー。9 以上は 8 に丸める |
| `--fullscreen` | — | 設定ファイルの値（なければ false） | フルスクリーンで表示する。`--scale` は無視する |
| `--shader KIND` | `nearest` / `smooth` | 設定ファイルの値（なければ nearest） | 拡大時の補間方式 |
| `--recent` | — | — | 最近使った ROM を新しい順に、1行に1件ずつ標準出力に表示して終わる（ROM の指定は不要） |
| `--headless` | — | — | ウィンドウ、音声デバイス、SDL を使わずに実行する |
| `--frames N` | 正の整数 | — | `--headless` と組み合わせる。N フレーム実行したら終わる |
| `--screenshot PATH` | パス | — | `--headless` と組み合わせる。終了時にフレームバッファを 24bit BMP で PATH に保存する |

- 優先順位: CLI オプション > 設定ファイル > 既定値。
- `--headless` で `--frames` を省略した場合は、エラーにする（終わらない実行を防ぐため）。

## 終了コード

| コード | 意味 |
|---|---|
| 0 | 正常終了（Esc、ウィンドウを閉じた、`--frames` に到達、`--help` / `--version` / `--recent`） |
| 1 | 実行時エラー（ROM を読めない、未対応のカートリッジ、SDL2 を読み込めない、BMP を書けないなど） |
| 2 | 使い方の誤り（未知のオプション、値がない、値が不正、ROM の指定がない） |

エラーメッセージは日本語で標準エラー出力に出す。使い方の誤りの場合は、続けて使い方も表示する。

## キー操作（ROM の実行中）

| キー | 機能 |
|---|---|
| 矢印キー | 十字キー |
| Z / X | B / A |
| Enter | Start |
| 右Shift | Select |
| F1 | セーブステートを保存（`<ROM>.state`） |
| F3 | セーブステートを復元（失敗したら標準エラー出力に理由を出し、実行を続ける） |
| Esc | 終了 |

## 環境と前提

- 実行時に `libSDL2-2.0.so.0` が必要。ただし `--headless`、`--help`、`--version`、
  `--recent` では不要で、SDL2 を読み込まない。
- macOS では Homebrew の `libSDL2.dylib` または SDL2 Framework を使う。見つからなければ
  `SDL2 が見つかりません。brew install sdl2 で導入してください。` と案内する。
- Linux で SDL2 が見つからない場合は、次のように案内する:
  `SDL2 が見つかりません。sudo apt install libsdl2-2.0-0 で導入してください。`
