# 契約: セーブステートのファイル形式（`.state`）

spec FR-011〜FR-013。すべてリトルエンディアン。

## ヘッダ（10 バイト）

| オフセット | サイズ | 内容 |
|---|---|---|
| 0 | 4 | マジック `"LGBS"`（0x4C 0x47 0x42 0x53） |
| 4 | 4 | フォーマットバージョン（u32、初版は 1） |
| 8 | 2 | ROM ヘッダのグローバルチェックサム（0x014E〜0x014F をそのままの順序で） |

## 本体

[data-model.md](../data-model.md) で SS 列が ○ の要素を、次の順に書く。
Cpu → Bus（WRAM、VRAM、OAM、HRAM、IO、IE/IF、バンクレジスタ、DMA 状態）→ Timer → Ppu →
Apu → Cartridge（外部 RAM、MBC レジスタ、RTC）→ Joypad。

- 真偽値は 1 バイト（0 / 1）で書く。
- 外部 RAM の長さはカートリッジから決まるので、本体のサイズはカートリッジごとに決まった値になる。
- 全体のサイズは `savestate-size (machine)` で計算できなければならない。書き込みの後に、
  実際に書いたバイト数とこの値が一致することを確認する（形式を変えたときに、
  サイズ計算の更新漏れを見つけるため）。

## 読み込み時の検証（この順に行う）

1. マジックが一致するか
2. バージョンが一致するか（一致しなければ拒否する。旧版の変換はしない）
3. グローバルチェックサムが、いま読み込んでいる ROM と一致するか
4. 残りのサイズが `savestate-size` と一致するか

1〜4 のどれかに失敗したら、Machine を**一切変更せずに**、理由を表す条件を通知する。
すべて通過したら書き込み、最後に APU のリングバッファを 0 クリアする。

## 互換性

- 形式を変えるときは、必ずバージョンを上げる。
- RuxBoy（`RXBS`）とは互換性がない（意図的）。
